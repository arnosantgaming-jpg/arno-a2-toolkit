Arno's A2 Toolkit for Windows

1. Install Npcap from https://npcap.com
   Leave "Restrict Npcap driver's access to Administrators only" unticked.
2. Unzip this folder anywhere, and run arno-a2-toolkit.exe.
3. Run AION 2 in borderless windowed mode, so the toolkit can read the game's minimap.

Your data is in %LOCALAPPDATA%\arno-a2-toolkit.
